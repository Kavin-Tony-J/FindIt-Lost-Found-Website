Lost-Found-Website
1. Project Overview
FindIt is a web-based Lost and Found application developed using Java and Spring Boot. It is intended to provide
a simple interface for reporting and viewing information about lost and found items. Confirm that the described
features match the current implementation before submission.
3. Technologies
Java; Spring Boot; Spring MVC; Thymeleaf; Spring Data JPA; Hibernate; Maven; HTML/CSS; and MySQL if
configured in the project.
4. Features
• Dashboard for item information
• Lost and found item reporting
• Display of reported items
• Form validation
• Database integration
5. Installation and Execution
Prerequisites: a compatible JDK, Maven or the Maven Wrapper, and the configured database software if
required.
1. Clone the repository and open the project folder.
2. Configure database settings in src/main/resources/application.properties.
3. Open the project in an IDE or terminal.
4. Run mvn spring-boot:run or run FinditApplication.java.
5. When startup succeeds, open http://localhost:8080 in a browser.
5. Configuration Notes
Do not commit real passwords, API keys, or other secrets to GitHub. The database name, dependencies, and
required configuration must match the actual project.
6. Purpose
This project demonstrates a Java web application using Spring Boot, MVC request handling, Thymeleaf
templates, and database persistence.
